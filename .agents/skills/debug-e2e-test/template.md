## Terms

Document status are draft, wip(work in progress) and done.

draft: AI Agent is drafting this document. User has not yet approve the document.
wip: start to debug according to this document.
done: all suspicious are done no matter issue was fixed or all possible reasons are rejected.

Suspicious status are suspected, proved, rejected or fixed.
suspected: it's possible but no solid prove
proved: proved by solid evidence such as log
rejected: rejected by solid evidence
